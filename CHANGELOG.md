# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/) and this project adheres to [Semantic Versioning](http://semver.org/).

## [1.1.0] 2026-06-11
### Added
- Added product variable replacement for configured PDP HTML blocks.
- Added the `pdpHtmlBlock:updated` browser event to support third-party widget reinitialization after PDP updates.
- Added a generated `html-block-<portal-name>` CSS class for rendered portal blocks.

## [1.0.0] 2026-04-10
### Added
- Initial release of PDP HTML Block extension
- Support for injecting configurable HTML blocks into various PDP portals
